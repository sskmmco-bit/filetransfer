# change_log/

One file per change that was actually made.

- **Filename:** `yyyymmdd_hhmmss_<slug>.md` — the date/time of the change (e.g. `20260617_151045_add-2fa-login.md`).
- **Records:** what was changed (files, DB migrations, behavior), a reference to the originating plan file in `../plans/`, and any deviations from that plan.

See the "Workflow rules" section in `../CLAUDE.md` for the full policy.
