# plans/

One file per planned change, created **before** any implementation.

- **Filename:** `yyyymmdd_hhmmss_<slug>.md` — the date/time the plan was created (e.g. `20260617_143022_add-2fa-login.md`).
- **Required sections:** Status (`planned` → `in-progress` → `completed`), Summary, Files affected (created/changed/deleted), Database changes, Effect on the current system.
- **Approval gate:** after the plan is written, manual user approval is required before implementation begins.

See the "Workflow rules" section in `../CLAUDE.md` for the full policy.
